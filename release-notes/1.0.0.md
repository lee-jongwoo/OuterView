# OuterView 1.0.0

First release of OuterView, a native macOS app for interview preparation.

- Create question sets and crop reading passages from PDFs.
- Practice with reading timers and record video answers.
- Review takes and export captioned MP4 videos.
- Share and import training sets as `.outerview` files.

## Requirements

- macOS 26.0 or later.
- Apple silicon or Intel Mac (universal app).
- Camera and microphone permissions for recording.

## Install

1. Download `OuterView-1.0.0.dmg` from the release assets.
2. Open the DMG and drag **OuterView** to **Applications**.
3. Eject the disk image and open OuterView from Applications.

The source-code ZIP and TAR archives are for developers; download the DMG to
install the app.
